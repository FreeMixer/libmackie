# libmackie

A C library for the Mackie Control (MCU) protocol that motorised MIDI control surfaces such as
the Behringer X-Touch speak: encoders and decoders for faders, buttons and lamps, V-Pots and their
LED rings, meters, scribble strips, the seven-segment displays and the host-connection handshake.
Pure functions over byte buffers: no I/O, no clock, no allocation. The host carries the MIDI bytes.

Work in progress.
